## 🔧 Technical Details

### Model Information
```
Model:     crownmerry/crown-humanizer-v2
API URL:   https://api-inference.huggingface.co/models/crownmerry/crown-humanizer-v2
Token:     HF_TOKEN (stored in .env.local)
Provider:  Hugging Face Inference API
```

### Request Flow
```
User Input → Frontend (Workspace.tsx)
           ↓
Backend (/api/humanize) → Validates user & credits
           ↓
Hugging Face API → crownmerry/crown-humanizer-v2
           ↓
Humanized Text → Frontend (displayed to user)
```

### API Parameters
```javascript
{
  inputs: "Humanize the following text:\n\n[user text]",
  parameters: {
    max_new_tokens: 2048,
    temperature: 0.7,
    top_p: 0.9,
    repetition_penalty: 1.2,
    do_sample: true
  },
  options: {
    wait_for_model: true,  // Waits if model is loading
    use_cache: false       // Always fresh results
  }
}
```

## 🐛 Troubleshooting

### Issue: "HF_TOKEN not configured"
**Solution:** Make sure `.env.local` exists with the token, and restart the dev server.

### Issue: "Model is loading"
**Solution:** Hugging Face models can take 20-30 seconds to "warm up" if they haven't been used recently. The API will wait automatically (`wait_for_model: true`).

### Issue: "Rate limit exceeded"
**Solution:** Free tier has rate limits. Wait a minute or upgrade your Hugging Face account.

### Issue: Empty response
**Solution:** Check the model output format in the Hugging Face logs. The code handles multiple response formats.
